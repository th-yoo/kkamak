## Task 2 — Known issue #7: capture the stray `hello` on stderr

**The finding.** `test/runtime.test.ts:283` calls `host.logger.log("hello")` to prove `StderrLogger` does not throw. `StderrLogger` (`src/runtime/system.ts:25`) really does write to stderr, so a bare `hello` line lands in every test run's output — noise that a reader cannot distinguish from a real diagnostic.

**Files:**
- Modify: `test/runtime.test.ts` — the single test whose name begins `a logger failure is the caller's problem` (at lines 281-284 on a pristine `main`; **locate it by that name, not by line number** — if Task 1 has already landed, its new `FileConfigSource` test sits earlier in the same file and has shifted this one down)

**Interfaces:** none produced or consumed.

- [ ] **Step 1: Replace the test with one that captures the write**

Replace that test in full:

```ts
  test("a logger failure is the caller's problem, not the kernel's — it must not throw here", () => {
    const host = createNodeHost({ root: dir, app: "x" })
    // Captured, not silenced: StderrLogger really writes, and letting it
    // write here leaks a bare "hello" into every test run's output where it
    // is indistinguishable from a real diagnostic (docs/known-issues.md #7).
    // Asserting on the spy also makes this test prove delivery, which the
    // not-to-throw assertion alone never did.
    const write = spyOn(process.stderr, "write").mockImplementation(() => true)
    try {
      expect(() => host.logger.log("hello")).not.toThrow()
      // Assert INSIDE the try: mockRestore() clears the call record, so
      // asserting after the finally sees zero calls and fails.
      expect(write).toHaveBeenCalledTimes(1)
      expect(String(write.mock.calls[0]![0])).toBe("hello\n")
    } finally {
      write.mockRestore()
    }
  })
```

**The assertion placement is not stylistic.** The obvious arrangement — assert after the `try`/`finally`, so the spy is guaranteed restored first — was written, run, and *failed*: bun's `mockRestore()` resets `write.mock.calls`, so `toHaveBeenCalledTimes(1)` sees 0. It typechecks perfectly, which is why only running it catches this. Assert inside the `try`; the `finally` still restores the spy even when an assertion throws.

`"hello\n"` — not `"hello"` — because `StderrLogger` appends the newline itself (`src/runtime/system.ts:25`).
